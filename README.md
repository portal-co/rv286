# rv286

## Description
Static recompiler from RISC-V (RV32I) to x86 (32-bit) ("rv286"). Aimed at running simple RISC-V binaries on x86 hardware.

## Goals
- [ ] Recompile RV32I to x86
- [ ] Support basic syscalls
